# نظام الشكاوى — جامعة بوليتكنك فلسطين

نسخة فرونت إند عربية تفاعلية لمشروع جامعي، باستخدام **HTML5 وCSS3 وJavaScript العادي**. استُخدمت صورة التصميم في `img` مرجعًا، وشعار الجامعة الأصلي دون استبدال. الصور الأصلية محفوظة كما هي.

## التشغيل

يمكن فتح `index.html` مباشرة في متصفح حديث. للتجربة على عنوان محلي ثابت، شغّل من مجلد المشروع:

```sh
npm start
```

ثم افتح **http://localhost:8080**. لا تحتاج إلى `npm install` أو أدوات بناء. يستخدم خادم المعاينة Node.js فقط لتقديم الملفات، ولا يستقبل شكاوى أو بيانات. إذا كان المنفذ مستخدمًا: `PORT=8081 npm start`.

عند تغيير المتصفح أو الانتقال بين `file://` والعنوان المحلي أو تغيير المنفذ، تختلف مساحة التخزين؛ استخدم العنوان والمتصفح نفسيهما لمتابعة بياناتك.

## ما الذي يمكنك تجربته؟

- الرئيسية: ست بطاقات تختار الخدمة وتفتح نموذج الشكوى.
- تقديم الشكوى: بيانات الطالب ثم تفاصيل المشكلة، تحقق عربي، رجوع يحافظ على البيانات، صورة اختيارية، وملخص قابل للمراجعة قبل التأكيد.
- المتابعة: البحث برقم الشكوى وعرض الحالة والرد إن وُجد.
- الأمثلة: `DEMO-1001` للإرسال، `DEMO-1002` للمراجعة، `DEMO-1003` للمعالجة، و`DEMO-1004` للحل وتجربة التقييم.
- التقييم: يظهر بعد الحل فقط ويُحفظ مرة واحدة لكل شكوى في هذا المتصفح، دون تغيير حالتها.
- المساعد: جرّب «الإنترنت في مبنى C سيئ وبفصل كثير». يستخرج الخدمة والموقع، ويتيح تعديل المسودة واستخدامها في النموذج. يسأل عن المعلومات الناقصة ويبحث في البيانات المحلية فقط.
- الوضع الليلي: يتبع إعداد الجهاز عند أول زيارة، ثم يحفظ اختيارك. الحركات تحترم تفضيل تقليل الحركة.

## تنظيم الملفات

| الملف | مسؤوليته |
| --- | --- |
| `index.html` | الصفحات الأربع، النموذج، المتابعة، نافذة المساعد وملخص المراجعة. |
| `css/styles.css` | الألوان المركزية، الوضعان، أحجام الشاشات والحركات. |
| `js/config.js` | الخدمات والحالات وحدود الصور وإعداد نطاقات البريد. |
| `js/storage.js` | قراءة الشكاوى وحفظها والبحث عنها والتقييمات؛ منفصل عن عناصر الصفحة. |
| `js/assistant.js` | قواعد التصنيف، الأسئلة التوضيحية وصياغة المسودة. |
| `js/app.js` | التنقل، التحقق، معاينة الصورة وعرض النتائج وتفاعلات الواجهة. |
| `js/theme-init.js` | اختيار الألوان قبل تحميل CSS لتجنّب الوميض. |
| `assets/` | الشعار، الرسم الجامعي، أيقونات SVG والخطوط المحلية. |
| `tests/` | اختبارات منطق البيانات والمساعد واختبار المتصفح. |

لتقييد نطاق البريد مستقبلًا، عدّل `acceptedEmailDomains` في `js/config.js` بعد تأكيد نطاقات الجامعة. القائمة فارغة حاليًا؛ يُتحقّق من صيغة البريد فقط ولا يُفترض نطاق غير موثّق.

يمكن ربط باك إند لاحقًا عبر استبدال طرق `PPURepository` في `js/storage.js` بطلبات إلى الخادم، مع إبقاء واجهة العرض منفصلة. ستحتاج النسخة الفعلية أيضًا إلى التحقق من البيانات على الخادم والمصادقة وإدارة حالات الشكاوى.

## حدود النسخة

هذه **نسخة تعليمية غير مرتبطة بالجامعة**. لا تُرسل أي شكوى أو تقييم إلى جهة خارجية. تُحفظ الشكاوى والتقييمات وتفضيلات الألوان في `localStorage` بهذا المتصفح. الأمثلة وهمية، وحالاتها ثابتة. كل شكوى جديدة تبدأ بـ«تم الإرسال» ودون رد مختلق، ولا يتغيّر وضعها بمرور الوقت.

الصور للمعاينة المؤقتة فقط بصيغ JPG/PNG وحتى 5MB؛ لا تُرفع إلى خادم ولا تُخزّن بصيغة Base64. المحادثة ومسودات النموذج غير المرسلة تبقى في الذاكرة وتختفي عند إعادة التحميل. لا تستخدم بيانات حساسة أو معلومات طلاب حقيقيين. حذف بيانات الموقع من إعدادات المتصفح يحذف الشكاوى والتقييمات. يظهر خطأ واضح إذا منع المتصفح الحفظ.

كل موارد الواجهة محلية ولا تحتاج إلى اتصال بالإنترنت. المساعد يستخدم قواعد بسيطة دون API أو مفاتيح سرية. خط Tajawal مضمّن بترخيص SIL Open Font License؛ نص الترخيص في `assets/fonts/OFL.txt`.

## الاختبارات

```sh
npm test
```

تشمل اختبارات المنطق: أرقام الشكاوى، الحالة الابتدائية، فصل الأمثلة، منع حفظ الصور، أخطاء التخزين، التقييم بعد الحل ومنع تكراره، وصياغة المساعد وأسئلته والبحث المحلي.

لإعادة اختبار الواجهة آليًا، شغّل خادم المعاينة ونسخة Chrome تجريبية على منفذ CDP 9222، ثم `node tests/browser-check.mjs`. الاختبار يستخدم ملف تعريف Chrome التجريبي المفتوح، ويمسح بيانات موقع المعاينة فيه قبل البدء. لا تشغّله على ملف تعريفك المعتاد. يختبر النموذج والمتابعة والتقييم والمساعد والموبايل والوضع الليلي، ويحفظ لقطات في `/private/tmp/ppu-qa`.
